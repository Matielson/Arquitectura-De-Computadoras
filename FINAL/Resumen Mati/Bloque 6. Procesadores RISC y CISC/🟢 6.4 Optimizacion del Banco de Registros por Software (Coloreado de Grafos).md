
Si el procesador no cuenta con ventana de registros por hardware, la responsabilidad de optimizar el uso de los pocos registros reales recae sobre el compilador.

- **Como funciona el Coloreado de Grafos?:**
	1. El compilador asume temporalmente que dispone de una cantidad infinita de "**registros virtuales o simbolicos**" y le asigna uno a cada variable del programa.
	2. Luego, el compilador mapea o asigna esos registros virtuales a la cantidad limitada de registros reales del procesador.
	3. Si dos variables no se usan al mismo tiempo (no se solapan en sus ciclos de vida), pueden **compartir el mismo registro fisico real**.
	4. Para resolver este mapeo de forma matematica y optima, el compilador utiliza la tecnica algoritmica denominada **Coloreado de Grafos**. Si los registros reales no alcanzan, las variables sobrantes se envian temporalmente a posiciones de memoria (lo que se conoce como derrame o *spill*).
