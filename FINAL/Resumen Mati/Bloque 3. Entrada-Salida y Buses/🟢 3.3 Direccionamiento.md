Como accede la CPU a esos registros? Hay 2 tecnicas exclusivas para que la CPU localize un registro de E/S:

1. **Espacio de E/S compartido con memoria (Memory-Mapped):**
	- **Como Funciona?:** Los registros de E/S y la memoria RAM comparten el mismo mapa de direcciones. Una direccion de memoria especifica (ej. 0x1000) no apunta a la RAM, sino a un registro del modulo E/S.
	- **Consecuencia:** Los registros se comportan igual que la memoria. **No existen instrucciones especiales de E/S**; la CPU usa las mismas instrucciones comunes de movimiento de datos (como MOV o LOAD) para leer o escribir en los dispositivos. Permite una programacion muy eficiente.

2. **Espacio de E/S separada de la memoria (Aislada):**
	- **Como funciona?:** Los registros de E/S estan en un mapa de direcciones totalmente diferente al de la memoria principal.
	- **Consecuencia:** Como comparten fisicamente el mismo bus de direcciones, la CPU requiere señales de control adicionales para avisarle al hardware si esta buscando una direccion en la RAM o en el mapa de E/S. Ademas, requiere un **conjunto limitado de instrucciones especificas de E/S** (distintas a las de memoria) para realizar los accesos.
