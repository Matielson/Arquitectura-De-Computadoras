 Para que una instruccion se ejecute en un procesador segmentado clasico, debe atravesar obligatoriamente estas **5 etapas secuenciales** (cada etapa tarda un ciclo de reloj, por lo que una instruccion requiere 5 ciclos en total para completarse):

1. **IF (Busqueda de Instruccion - Instruction Fetch):** 
	- *Que hace:* Accede a la memoria de instrucciones para traer la instruccion que indica el PC.
	- *Accion adicional:* Incrementa el valor del PC para apuntar a la siguiente.
	- *Recurso de hardware utilizado:* **MI** (Memoria de Instrucciones).

2. **ID (Decodificacion de Instruccion - Instruction Decode):**
	- *Que hace:* Determina el codigo de operacion (que debe hacer la CPU). Accede al banco de registros para buscar los operandos que va a usar. Si es necesario, calcula el valor de un operando inmediato con extension de signo.
	- *Recurso de hardware utilizado:* **BR** (Banco de Registros).

3. **EX (Ejecucion de Instruccion - Execute):**
	- *Que hace:* Realiza la operacion aritmetica o logica correspondiente con los operandos.
	- *Recurso de hardware utilizado:* **ALU** (Unidad aritmetico - logica).

4. **MEM (Acceso a Memoria - Memory):**
	- *Que hace:* Escribe o lee datos desde la memoria de datos (solo si la instruccion lo requiere, como un LOAD o un STORE).
	- *Recurso de hardware utilizado:* **MD** (Memoria de Datos).

5. **WB (Escritura en Registro - Write Back):**
	- *Que hace:* Guarda o almacena el resultado final obtenido de vuelta en el banco de registros.
	- *Recurso de hardware utilizado:* **BR** (Banco de Registros).

**Como se coordinan fisicamente las etapas? (Los registros Interetapa):** Como cada unidad de hardware (MI, BR, ALU, MD) esta operando con instrucciones distintas al mismo tiempo, las señales de control deben segmentarse. Para lograr esto, se requiere **intercalar registros fisicos de almacenamiento (latches) entre cada una de las etapas**. Estos registros actuan como barreras de aislamiento que retienen los datos y señales de control para que cada etapa trabaje de forma independiente sin mezclar la informacion de las diferentes instrucciones.
